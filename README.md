# PomidorQA — Мои автотесты с марафона «Автоматизация на Playwright + TypeScript» 🍅

Репозиторий содержит базу автотестов (Unit, API и E2E), написанных мной в рамках марафона PomidorQA. 

Продукт доступен как живой сайт: [aiqa.su/pomidorqa](https://aiqa.su). Здесь — только мои автотесты и вспомогательный код для них.

## 🛠 Технологический стек
* **Тест-раннер:** Playwright
* **Язык программирования:** TypeScript
* **Статический анализ кода:** ESLint
* **Непрерывная интеграция:** GitHub Actions

---

## 🚀 Установка и запуск (Локально)

### 1. Установка зависимостей и браузеров
```bash
npm install
npx playwright install chromium
```

### 2. Запуск тестов
```bash
npm run test:unit   # Unit — без сети и без браузера
npm run test:api    # API — HTTP-запросы к локальному мок-серверу
npm run test:e2e    # E2E — реальный браузер на живом aiqa.su/pomidorqa
npm test            # Все три уровня сразу (Unit, API, E2E)
```

### 3. Просмотр отчетов и линтера
```bash
npm run lint        # Статический анализ кода (ESLint)
npm run report      # Открыть HTML-отчёт последнего прогона тестов
```

### 4. Изменение базового URL (при необходимости)
По умолчанию E2E-тесты идут на продакшен (https://aiqa.su). Если нужно направить их на локальный стенд, переопределите переменную окружения:
```bash
POMIDORQA_BASE_URL=http://localhost:3000 npx playwright test --project=e2e
```

## 📂 Структура проекта
* `src/pyramid/` — вспомогательный код: чистые функции (unit) и локальный мок-сервер (api).
* `tests/unit/` — тесты на пересечение слотов по времени, форматирование времени, валидацию пароля.
* `tests/api/` — тесты на регистрацию, бронирование, гонку за слот через HTTP к локальному мок-серверу.
* `tests/e2e/` — реальный сценарий бронирования и негативный сценарий логина в браузере.

## ⚙️ Настройка CI (GitHub Actions)
В репозитории развернут и настроен собственный пайплайн непрерывной интеграции (`.github/workflows/playwright.yml`). 
При каждом событии **`push`** и **`pull_request`** в ветку `main` автоматически запускаются:
1. Проверка стиля и ошибок кода через **`npm run lint`**.
2. Полный прогон автотестов на базе **Playwright** с автоматическими ретраями для стабильности билда.
